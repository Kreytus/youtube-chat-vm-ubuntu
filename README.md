# youtube-chat-vm-ubuntu
script to do Chat uses ubuntutu!

# setup
get virtualbox if you dont already.

you will have to go to install directory and go to sdk and the one folder in there.
then run:
```
pip install setuptools
pip install vbox-sdk
```
now you have vboxapi. do this:
```
pip install virtualbox pyvbox pytchat pywin32 flask flask-sock
```
then edit config.json
and run the script

report any issues with running to the issues tab.

# commands list for your stream:
```
COMMANDS:
(can chain)

!help (only works if chat overlay is there)

!key [key_name]

!repeat [key] [times]

!combo [key_names...] (SEPERATE KEYS WITH SPACE!)

!type [text]

!send [text]

!move [x] [y] (dont put big numbers, this moves the mouse more then u think. also: y is inverted for sum reason)

!scroll [num]

!click

!rclick

!mclick

!revert

!restart

!start

!cmd [text] (opens run and puts cmd - whatever text you put here)

!run [text] (opens run and puts cmd - whatever text you put here (combined with !cmd cause ubuntu doesnt have a win+r alternative) )
```
